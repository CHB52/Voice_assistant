#  Voice Assistant

A Python-based voice assistant that listens to user commands and responds through speech. The assistant can perform various tasks such as providing the current time and date, opening websites, performing web searches, telling jokes, and sharing motivational quotes.

---

## Features

| Command | Example |
|----------|----------|
| Greeting | "Hello", "Hi" |
| Current Time | "What's the time?" |
| Current Date | "What's today's date?" |
| Day of Week | "What day is it?" |
| Open YouTube | "Open YouTube" |
| Open Google | "Open Google" |
| Open GitHub | "Open GitHub" |
| Google Search | "Search Python tutorials" |
| Tell a Joke | "Tell me a joke" |
| Motivational Quote | "Give me a motivational quote" |
| Help | "What can you do?" |
| Exit | "Goodbye", "Exit" |

---

## Technologies Used

- Python 3
- SpeechRecognition
- pyttsx3
- PyAudio

---

## Installation

Install the required dependencies:

```bash
pip install -r requirements.txt
```

---

## Run the Application

```bash
python assistant.py
```
